# SpeedKetchup for Home Assistant

[![Open your Home Assistant instance and show the add app repository dialog with this repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fgatispei%2Fspeedketchup-homeassistant)

Home Assistant app repository for [SpeedKetchup](https://github.com/gatispei/speedketchup),
a periodic internet speed tester with charts, a full history and MQTT sensors.

## Installation

Click the button above, or in Home Assistant go to **Settings** > **Apps** >
**Install app**, open the menu at the top right, pick **Repositories** and add

```
https://github.com/gatispei/speedketchup-homeassistant
```

Then find **SpeedKetchup** in the list, install and start it.
